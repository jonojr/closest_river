Queues every tile from zoom 0 up to the zoom you pick to be rendered into the cache, lowest zoom first, so no visitor waits on them. Use it after a deploy that changes the cache keys; the daily sync already re-renders the tiles it evicts. It does the same as manage.py precache_tiles.

The tasks share the osm queue's single slot, so a sync waits for any still queued: run it during the day. A tile that is already cached costs only a lookup, so running it again is harmless, but queueing it twice doubles how long the queue is held.
